# dont

A functional CLI forcing function for autonomous LLM harnesses.

## Purpose

`dont` interrupts unsupported assertions and requires grounding before claims become trusted. It provides a structured, machine-readable "Envelope" interface for agents to:
- Conclude claims with dependency tracking.
- Define terms with SK11 type-text validation.
- Ground claims with structured evidence locators (file paths, line spans).
- Audit evidence drift.

## Current state

Functional Rust implementation with a mature CLI surface.

Key files:
- `src/main.rs` — CLI entry point and business logic.
- `src/envelope.rs` — JSON Envelope and Error protocol.
- `src/model.rs` — Epistemic state transition logic.
- `src/store.rs` — Cozo-based persistence layer.
- `openspec/specs/` — Formal specifications.
- `docs/` — mdBook documentation.

## Working norms

- Run `wai status` first.
- Use `dont --json` for machine-readable interaction.
- Every error provides a `remediation` field with the next best command.
- Follow TDD: write a failing test in `tests/` before fixing/adding logic.

## Install

```bash
# macOS & Linux (curl)
V=$(basename "$(curl -fsSLI -o /dev/null -w '%{url_effective}' \
  https://github.com/charly-vibes/dont/releases/latest)" | sed 's/^v//')
TGT="$(uname -s | tr '[:upper:]' '[:lower:]')_$(uname -m | sed 's/^x86_64$/amd64/; s/^aarch64$/arm64/')"
curl -fsSL "https://github.com/charly-vibes/dont/releases/download/v${V}/dont_${V}_${TGT}.tar.gz" | tar xz
chmod +x dont && sudo mv dont /usr/local/bin/
```

Or via Cargo: `cargo install dont-cli`.
